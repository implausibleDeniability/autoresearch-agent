# 19k-token development data

This directory contains 17 complete Industry Documents examples used for development. Together they
contain 19,346 `o200k_base` tokens and 11,162 words, including 74 labeled people and 203 labeled PII
values. Nine documents are negative examples. There is no separate test split yet.

`ground_truth.json` maps each document ID to its document-scoped list of people using the
[ground-truth value format](../../README.md#ground-truth-labels).
